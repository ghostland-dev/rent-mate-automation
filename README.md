# Rent Mate

Rental management automation for landlords.

## Features

- Single-page React app

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/rent-mate-automation.git
cd rent-mate-automation
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
